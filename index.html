THIS IS THE DEVELOPMENT ENTRY FILE — IT NEEDS THE DEV SERVER

You opened index.html straight from the folder. This file only points at the source code, so nothing can render without Vite running.

Option 1 — run it (development):

npm install
npm run dev

Option 2 — open the finished build (no server needed):

npm run build

then double-click dist\index.html — a single self-contained file that runs offline with no install.

คุณเปิดไฟล์ index.html ตัวนี้ตรง ๆ จากโฟลเดอร์ ซึ่งเป็นไฟล์สำหรับตอนพัฒนา จึงขึ้นจอขาว
ให้รัน npm run dev แล้วเปิด http://localhost:5173
หรือรัน npm run build แล้วดับเบิลคลิกไฟล์ dist\index.html ซึ่งเปิดได้เลยโดยไม่ต้องมีเซิร์ฟเวอร์
