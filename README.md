# THEOS-2 MAE SAI COMMAND

**Multi-Sensor Geospatial Serious Game & Integrated Disaster Decision Support System**
ระบบภารกิจจำลองสถานการณ์และสนับสนุนการตัดสินใจบริหารจัดการอุทกภัยแม่สาย ด้วยข้อมูลภูมิสารสนเทศแบบหลายช่วงคลื่น

ผลงานทีม revenge (โรงเรียนสิงห์บุรี) สำหรับ *The GEO Quest 2026 : THEOS-2 Geospatial Mission Design Challenge* (GISTDA) · ประเด็น 05 การจัดการภัยพิบัติ

ผู้เล่นสวมบท **ผู้บัญชาการ EOC อำเภอแม่สาย** ตัดสินใจภายใต้หลักฐานที่ไม่เคยครบ ใน 3 องก์ — เฝ้าระวัง (T−48 → T0) · วิกฤต (T0 → T+36) · ฟื้นฟู (วันที่ 2 → 60) — ทุกตัวเลขบนจอติดป้ายที่มาข้อมูล 4 สี: วัดจริง · ภาพ THEOS-2 · เรดาร์ · ค่าสถานการณ์

> รายละเอียดกติกา ค่าตั้ง และสคริปต์ทดสอบทั้งหมดอยู่ใน [`CLAUDE.md`](CLAUDE.md) — ไฟล์นี้เป็นภาพรวม

## ลำดับการเล่น

1. **หน้าเปิดเกม** — ใส่ชื่อ (ใช้จับคู่รอบ 1/รอบ 2 และแฟ้มประวัติ) · สร้างตัวละคร chibi · เลือกโหมด Beginner / Expert · วิธีเล่น · โหมดฝึกเจ้าหน้าที่ · ครูเลือก Stress Test
2. **แบบทดสอบก่อนเรียน** (ข้ามได้)
3. **องก์ 1 → คืนวิกฤต T0 → องก์ 2 → องก์ 3** — จบแต่ละองก์มีสรุป เกรด S/A/B/C และ "ถ้าคุณเลือกอีกทาง"
4. **สรุปภารกิจ** — คะแนน (เต็ม 1000) รายการตัดสินใจทุกข้อ เหรียญ ยศ บันทึกคะแนนลง Leaderboard
5. **แบบทดสอบหลังเรียน**

| องก์ | ช่วงเวลา | ผู้เล่นตัดสินใจอะไร |
| --- | --- | --- |
| **1 เฝ้าระวัง** | T−48 → T0 | ตั้งฐาน → เลือกเป้าหมาย THEOS-2 ตามเมฆพยากรณ์ (2 เป้า/รอบ, 3 รอบ) → แปลภาพหารอยดินถล่มใหม่ (ค่า L — ระวังนา เงาเมฆ รอยเก่า) → วัดลำน้ำบนภาพ Pan 0.5 ม. (ค่า N) → เลือกแผนแนวตลิ่ง 4 แบบ → สั่งอพยพรายโซนจาก 10 โซน |
| **คืนวิกฤต T0** | T0 | เกมการ์ดแบบผลัดตาสู้ "มวลน้ำ" — พลังทั้งหมดมาจากสิ่งที่เตรียมในองก์ 1 · แพ้ = ตลิ่งแตก โซนเสี่ยงที่สุดน้ำลึกขึ้นตลอดองก์ 2 |
| **2 วิกฤต** | T0 → T+36 | สั่ง THEOS-2 ถ่ายผ่านช่องเมฆหาผู้ติดค้าง · โดรนส่องจุดอับ · ตั้งเสาสื่อสาร · ตัดไฟ · สูบน้ำ · วางแผนเส้นทางเรือเอง (ริมแม่น้ำ / น้ำลึก ≥ 1.6 ม. / ไฟรั่ว = เรือล่มหรือโดนไฟช็อต) · ส่งผู้บาดเจ็บไปโรงพยาบาล |
| **3 ฟื้นฟู** | วันที่ 2 → 60 | ตัดสินเยียวยาหลังคาจริง 8 หลังจากภาพก่อน/หลัง + ไทม์ซีรีส์เรดาร์ 14 วัน: ท่วม ≥ 7 วัน ฿9,000 · มีโคลนเพิ่ม ฿10,000 · หลักฐานขาด → สำรวจภาคพื้น (+2 วัน ฿1,500) · ต้องยืนยันคำตัดสินก่อนเห็นผล |

### เวลาในเกม

ไม่มีนาฬิกาเดินเอง เวลาเดินเมื่อ (1) **สั่งการ** — ผลเกิดทันทีและกินเวลาสั่งการ หรือ (2) **กดแถบเวลา** ใต้แผนที่: `+1 ชม.` · `เดินเวลา → เหตุการณ์ถัดไป` · `ให้ THEOS-2 ถ่ายรอบ Pn` · `ข้ามไปจบองก์` (เมื่อไม่มีงานค้าง) — เหตุการณ์สำคัญ (ภาพพร้อม น้ำถึงเกณฑ์ พายุ สายด่วน ทีมงานเสร็จ ฯลฯ) หยุดการเดินเวลาให้ตัดสินใจ ระหว่างกระโดดเวลามีคัตซีนสั้น ๆ คลิกเพื่อข้ามได้

**คีย์ลัด:** `Space` เดินเวลาไปเหตุการณ์ถัดไป · `Enter` ยืนยัน / `Esc` ยกเลิกในหน้าต่างยืนยัน (Space ไม่ยืนยัน กันกดติดมือ) · `Ctrl+Shift+L` แผงครู

## กฎการตัดสินใจ (`src/lib/sim.js`)

```
SFVI = 0.30·W + 0.25·R + 0.20·L + 0.15·N + 0.10·P        (≥ 0.62 = หลักฐานพอสั่งอพยพ)
```

| | นิยาม | ที่มา |
| --- | --- | --- |
| **W** | ระดับน้ำสถานีบ้านถ้ำผาจม ÷ 4.20 ม. | วัดจริง |
| **R** | ฝนสะสมบ้านโจตาดา ÷ 250 มม. | วัดจริง |
| **L** | รอยดินถล่มใหม่ที่ผู้เล่นระบุจากภาพ THEOS-2 ÷ รอยทั้งหมด | ภาพ THEOS-2 |
| **N** | 1 − ความกว้างลำน้ำที่วัดได้ ÷ 150 ม. | ภาพ THEOS-2 |
| **P** | สัดส่วนหลังคาอาคาร GISTDA ในแนวน้ำท่วมของโซน | ภาพ + ค่าสถานการณ์ |

- **Veto 1** — ระดับน้ำ ≥ 4.20 ม. ต้องอพยพทันที
- **Cloud rule** — เมฆ > 60% หรือภาพล่าสุดเก่ากว่า 48 ชม. → น้ำหนัก L ลดลง ความเชื่อมั่นต่ำ · เป้าหมายที่เมฆบังไม่ได้ภาพ
- **ลำน้ำแคบ** — วัดได้ต่ำกว่าครึ่งของ 150 ม. → เกณฑ์เตรียมพร้อม 4.01 ม. ลดลง 0.20 ม.
- **เตือนผิด** — สั่งอพยพโดยหลักฐานไม่พอ ความเชื่อมั่นลด 5 / 15 / 40 และคนไม่เชื่อคำเตือนครั้งต่อไปมากขึ้น · สั่งครั้งแรกในองก์ 2 = เตือนช้า (−30)

ระดับน้ำ ฝน และเมฆเป็นฟังก์ชันของเวลาภารกิจ (`HYDRO` ใน `missionConfig.js`) — ผู้เล่นเปลี่ยนว่าใครได้รับคำเตือนเมื่อไร ไม่ได้เปลี่ยนน้ำ · ทุกเกมสุ่มสถานการณ์ใหม่ (`?seed=N` ตายตัว)

### คะแนน (เต็ม 1000)

**คะแนนผลงาน × ตัวคูณการตัดสินใจ − คำใบ้**
- ผลงาน: THEOS-2 200 · อพยพ 200 · ผู้ติดค้าง 200 · เยียวยา 200 · โลจิสติกส์ 100 · ความเชื่อมั่น 100 — ส่วนที่ไม่ได้ทำได้ 0 (ไม่มีคะแนนฟรี)
- ตัวคูณนับครั้งที่ตัดสินใจผิด / ข้าม ทั้งภารกิจ: ≤ 7 ครั้ง ×1.0 · 8–11 ครั้ง ×0.85 · 12 ครั้งขึ้นไป ×0.7
- คำใบ้: เปิดขั้น 2 หัก 10 แต้ม ขั้น 3 หักเพิ่มอีก 20 แต้ม ต่อหัวข้อ (ขั้น 1 ฟรี · เปิดซ้ำไม่หักซ้ำ · รวมไม่เกิน 100)

## โหมด

| | |
| --- | --- |
| **Beginner** | ผู้ช่วยสอน + คำใบ้แบบบันได (ถามชวนคิด → ชี้ที่ข้อมูล → เฉลยบางส่วน) · การ์ด "ผลที่จะเกิด" บอกว่าเตือนผิด/ทันเวลา/เสียเปล่า · chibi ชี้ปุ่มถัดไป · เห็นจุดอันตรายบนเส้นทางเรือ |
| **Expert** | งบ ทีม เรือ โดรน น้อยกว่า · ไม่มีคำใบ้ · การ์ดผลที่จะเกิดแสดงแค่ต้นทุน — ต้องประเมินความเสี่ยงเอง · ปลดล็อกเมื่อได้ยศหัวหน้าชุด |
| **โหมดฝึกเจ้าหน้าที่** | ระบบสนับสนุนการตัดสินใจครบ แต่ไม่มี chibi ฉากบอส เพลง หรือเอฟเฟกต์ตลก (`?officer`) |
| **Stress Test** | ครูเลือกที่หน้าเปิดเกม: ข้อมูลหาย · ถนนขาด · เวลาลดลง (`?stress=data,roads,time` หรือ `?stress=all`) — ปิด Stress = ฉากเหมือนเดิมทุกอย่าง |

**URL อื่น ๆ:** `?unlock` ครูปลดล็อกทุกโหมด · `?mode=expert` · `?seed=N` · `?perf=lite|full` โหมดประหยัดสำหรับเครื่องช้า · `?mute` · `?demo` ข้ามหน้าเปิดเกม/แบบทดสอบ (ไม่นับสถิติ) · `?rec` เปิดเฉลยให้สคริปต์อัดคลิป (ห้ามใช้ตอนเล่นจริง)

## แผงครู (Sandbox Test)

กด `Ctrl+Shift+L` (หรือไอคอนฐานข้อมูลจาง ๆ มุมขวาบน)

- **ภาพรวม** — เกณฑ์ของทีม: ≥ 70% ของผู้เล่นเปิดข้อมูล ≥ 3 ชั้นก่อนตัดสินใจครั้งแรก · คะแนนหลังเรียนเพิ่ม ≥ 30% · อ่านกติกา < 10 นาที
- **เทียบรอบ 1 → รอบ 2** — Paired t-test รายตัวชี้วัด จับคู่ด้วยชื่อผู้เล่น (ต้องใช้ชื่อเดิมและกดบันทึกคะแนน)
- **Export CSV 4 แบบ** — รายผู้เล่น · รายการตัดสินใจ · การขอคำใบ้ · รอบ 1 เทียบรอบ 2

ข้อมูลเก็บใน localStorage ของเครื่องนั้นเท่านั้น (ไม่มี server) · เปิดเกมหลายแท็บในเครื่องเดียวได้ บันทึกรวมกัน · ถ้าเครื่องบันทึกไม่ได้ (พื้นที่เต็ม/เบราว์เซอร์บล็อก) แผงครูจะขึ้นแถบแดงให้ส่งออก CSV ก่อนปิด · รูปหน้าผู้เล่น (ถ้าอัปโหลด) อยู่ในเครื่องเท่านั้น ไม่เข้า Log / CSV / Leaderboard (PDPA)

### เสียบข้อมูลจริงจาก GISTDA

1. วางไฟล์ใน `src/data/` (Shapefile → GeoJSON EPSG:4326 ด้วย QGIS/mapshaper)
2. เพิ่ม `import` ใน `missionConfig.js` แล้วใส่ใน `DATA.radarFlood` / `DATA.landslides` / `DATA.buildings` / `DATA.theosImagery.before|after`
3. `npm run build` — ขยายไปลุ่มน้ำอื่นได้ด้วยการเปลี่ยนไฟล์ข้อมูลเชิงพื้นที่และค่าใน config
